# Haishabet

Plataforma de apostas e cassino online (foco em jogos tipo "tigrinho") para o mercado brasileiro regulado pela **Lei 14.790/2023**.

## Estrutura

- `mobile/` — App do usuário final (Flutter — Android v1, iOS depois)
- `web/` — Dashboard administrativo (React + Next.js + TypeScript)
- `backend/` — API REST + SignalR (C# / .NET 8 — ASP.NET Core)
- `doc/` — Documentação completa do projeto

## Documentação

Toda a documentação técnica e de produto está em [`doc/`](doc/README.md). Comece por lá.
